## Posting rules
Attach the image, do not paste the image URL as text.
One group per 30 minutes. Do not paste the same text into ten groups in one hour: identical bulk posting is the fastest route to a ban.
Change the first line between groups. Keep the link identical.
If a group is a marketplace or classifieds group, drop the image and post only the one line version plus the link.
